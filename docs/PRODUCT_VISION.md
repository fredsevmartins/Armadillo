# Product vision

Help reviewers check whether manually annotated claims/evidence quote their original document, inspect declared links and optionally obtain explainable graph closure. Priorities: correctness, immutable inputs, reproducibility, transparent assumptions, interoperability and simple installation.

MVP success: offline installable CLI, strict errors, deterministic provenance and a tested optional real adapter. Presence is not scientific validity or entailment. Measurable engineering differences from the reference workflow: zero runtime dependencies, no AI credentials, strict bounded input and explicit compatibility checks. No claim of superior accuracy or performance.
